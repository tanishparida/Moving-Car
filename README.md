# Moving-Car

![Moving Car](./Screenshot%202026-10-10%20at%206.28.57%E2%80%AFPM.png)

This is the repository for a differential drive moving car, which is powered by 8-AA batteries. It drives with 2 800-RPM Pololu motors and is run by an ESP-32. It can go in any direction for any distance with its IMU and motor encoders. It has a top speed around 2 m/s.
